# Dynamic Sales Dashboard - Power BI

## 📌 Overview

This project presents an interactive Power BI Sales Dashboard designed to monitor business performance through key performance indicators (KPIs), sales trends, profitability analysis, and product performance insights.

The dashboard enables users to explore sales data using dynamic filters and visually analyze revenue, profit, orders, and category-level performance.
